## Acronyms & terms
| Term | Meaning | Notes |
|------|---------|-------|
| OCIO | Office of the Chief Investment Officer | The Co-Op's team |
| OPTrust | OPSEU Pension Trust | Employer / pension fund |
| Co-op | Co-op student / intern | The Co-Op's role |
| Macro theme | A tracked macroeconomic narrative | Monitored for progress + investment implications |
| MacroAgent / MacroBasis | Internal project | Weekly standardized macro dashboard report |
| AIP | Annual Investment Plan ("Back Pocket Document") | Upstream source of theses, figures, baselines |
| CUSMA | Canada–US–Mexico Agreement | Trade theme; serial annual reviews base case |
| SVIK | Germany €500B special infrastructure fund | Tracked via BMF monitoring reports |
| OBBBA | US fiscal package | Front-loaded stimulus / back-loaded cuts |
| COFER | IMF reserve-currency composition data | Tier 1 source, Currency Debasement theme |
| TIC | US Treasury Int'l Capital (foreign holdings) | Tier 1 source, Currency Debasement theme |
| SIPRI | Stockholm Int'l Peace Research Institute | Military-spending source, Fiscal theme |
| WGC | World Gold Council | Central-bank gold statistics, Currency theme |
| State file | `MacroBasis_State_YYYY-MM-DD.md`, the carry-forward state | The prior report for Phase 0 and Phase 5: statuses, anchors, watch items, histories. Written fresh every run |
| Baseline mode | Run with no state file attached | All statuses Held; confirm with the Co-Op first |
| Chart slots | Named cells the Co-Op fills with their own charts | The agent never generates, describes or fabricates a chart |
| Quadrant highlight | The whole current quadrant shaded on the AIP risk map | Replaced the dated dot marker (30 Jul 2026) |
| Week by Week Development | Back-matter history page: per theme, weekly light dots since June + a since-AIP verdict chip + "How it developed" | Replaced the Theme Light History heatmap (19 Aug 2026) |
| Regime signs | Weekly +/- per Inflation and Growth | The pair IS the quadrant coordinate: (+,+) Inflation, (+,-) Stagflation, (-,+) Productivity Boost, (-,-) Deflation |
| Performance / Valuations / Leverage / Dry powder | The Illiquids page's 2x2 framework grid categories (6 Aug 2026) | Returns vs public alternatives / richer-or-cheaper tells / how much debt and how measured / capital demand |
| Status governor | Rule set scoring the theme lights | Net score (direction × materiality, ±3) + tape veto; see the Evaluator |
| Tape veto | The week's tradeable tape materially contradicts the news flow | The light caps at Held and the status line names both sides |
| Checked-null | A driver or watchpoint searched with nothing in window | Recorded in triage, never silently omitted |
| Recency gate | Only developments published inside the window count | Older material may appear marked "for context" only |
